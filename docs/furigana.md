## 讀音依據

假名依使用者先前提供於 `lyrics/translations/` 的 10 份日文歌詞 PDF 整理；原檔名、來源連結與 SHA-256 見 [PDF 來源紀錄](../lyrics/translations/sources.json)。依 PDF 內原文與小字的對應位置逐句核對，保留原 LRC 的字句、標點及大小寫，不從外部歌詞服務覆蓋原文。羅馬字依各句假名轉寫並整理分詞，英文片段保持英文。

同字依歌詞情境處理，例如：

- 〈きらり〉的「永遠」使用「とわ」；〈花〉使用「えいえん」。〈旅路〉的「永遠を求めています」為「えいえん」，結尾「永遠なる光の中」為「とわ」。
- 〈まつり〉的「愛しか」為「あいしか」，「愛しき」為「いとしき」；〈満ちてゆく〉的「愛でて」為「めでて」。
- 〈何なんw〉的「行く」與「行って」分別保留「ゆく」與「いって」，「言うた」採 PDF 的「ゆうた」。〈Workin’ Hard〉的「実に」採「げに」。

## 維護與驗證

`furigana.js` 的鍵值必須與 `src/song-lyrics.js` 的原文完全相同。日文歌目前為 `readingsStatus: "ready"`；之後若新增未整理的日文歌詞，須一併補齊兩種讀音，或明確改回 `pending`。個別人工修正仍可放在 `src/furigana-corrections.js`。

`npm run check:lyrics` 檢查漢字是否皆有假名、假名標記是否合法、移除註音後是否保持原文，以及羅馬字是否缺漏或混入日文。`npm run check:karaoke` 檢查羅馬字與原文假名的逐字時間對齊。DOM smoke 檢查 19 首的讀音控制、假名／羅馬字／並列切換與原始時間碼。

讀音完成不代表影片時間已核對：936 行原文、中文與時間欄位維持原資料，所有歌曲仍標示「LRC 時間試播・待校正」，尚不啟用逐字時間。
