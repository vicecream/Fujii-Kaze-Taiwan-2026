# 放入 marumaru 中文譯詞

這裡保存你提供的 15 份 PDF，並已抽取為同名歌曲 ID 的 `.zh.txt` 雙語對照，例如 `Prema.zh.txt`、`Matsuri.zh.txt`。中文已加入目前字幕，共 672 列；PDF 未提供對應中文的部分保留待補。完整結果與待補時間見 [匯入紀錄](../../docs/translation-import.md)。

可以貼入純中文，或整段原文與中文的雙語對照。雙語內容有助於處理不同版本的分句與重複段落；不用自行補時間碼，也不用強制與 LRC 行數一致。若內容附有譯者及原始來源註記，請一併保留，後續匯入時核對署名。

放好後告訴我「中文譯詞已放好」，我會對照現有 LRC 原文，將譯文加入對應字幕列；無法確定對應位置的部分會另列待確認，不直接依行號硬配。

`sources.json` 保存檔名、PDF 雜湊、marumaru 參考頁及匯入狀態。PDF 僅註記「MARUMARU 提供」，未列個別譯者，因此記錄為提供來源；不自行推定作者。`extracted-pairs.json` 與 `alignment.json` 分別保存抽取段落及已核對的字幕映射。各頁連結亦可查看 [19 首 LRC 來源清單](../../docs/lyric-sources.md)。
